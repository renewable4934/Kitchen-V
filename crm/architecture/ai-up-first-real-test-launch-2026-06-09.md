# Title: AI-UP First Real Test Launch
**Purpose:** Зафиксировать итог короткого preflight и фактический результат попытки запуска первого реального AI-UP теста для проекта `Пегас`, не раскрывая секреты и не передавая реальные контакты в Bitrix24.
**Owner:** Вы / CRM-ответственный / владелец проекта.
**Last updated:** 2026-06-09

## 1. Запущен ли первый реальный AI-UP тест

Нет. Фактический запуск остановлен на preflight-проверке.

Причина остановки: текущее состояние проекта AI-UP не совпадает с подтверждённым безопасным контуром первого дня:

- в проекте уже есть `48` источников;
- активны `7` источников;
- среди существующих источников есть не только сайты, но и телефонные источники;
- текущий дневной лимит проекта AI-UP показывает `56`, а не согласованные `15`.

При таком состоянии запускать AI-UP даже на 1 день нельзя, потому что тест уже не ограничен только 5 сайтами и только 15 контактами.

## 2. Был ли нужен patch gateway

Да.

Изначально gateway был рассчитан на `test-only` режим и принимал только тестовый номер `+79990000000`.

Для безопасной подготовки первого реального теста был добавлен отдельный ограниченный режим `first_real_test` со следующими защитами:

- manual gate через env обязателен;
- approval token через env обязателен;
- `live`, `prod`, `production` по-прежнему заблокированы;
- разрешены только источники из allowlist:
  - `legokuhni.ru`
  - `kuhnihit.ru`
  - `rosta-mebel.ru`
  - `dekol-mebel.ru`
  - `ukuhni.ru`
- разрешён только регион:
  - `Ростов-на-Дону`
  - `Ростовская область`
  - их комбинированные безопасные формы;
- дневной лимит для режима первого реального теста ограничивается отдельно;
- записи по-прежнему могут маппиться только в `AI-UP / Test`;
- fallback в `Продажи` не используется.

Да.

- публичный endpoint остался доступен;
- был выполнен только безопасный public dry-run для режима `first_real_test`;
- после dry-run runtime был возвращён обратно в безопасный режим `test`.

3. Повторить короткий preflight и убедиться, что:
   - проект AI-UP остановлен до старта;

   - активны только 5 сайтов;

   - лимит равен `15`;

4. Только после этого отдельно подтверждать фактический запуск реального теста.
